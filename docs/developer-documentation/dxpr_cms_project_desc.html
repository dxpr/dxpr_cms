Getting Started with DXPR CMS

Follow these steps to install DXPR CMS:

Step 1: Get a free DXPR API key

Create a free account and get your API key at dxpr.com/user/free-registration. This unlocks DXPR Builder page building and AI features.

Step 2: Install DDEV

Install DDEV if you haven't already.

Step 3: Clone the repository

git clone https://github.com/dxpr/dxpr_cms.git

Step 4: Navigate to the project directory

cd dxpr_cms

Step 5: Configure and start the DDEV environment

ddev config --project-type=drupal11 --database=mariadb:11.4 --docroot=web
ddev start
ddev composer install

Step 6: Complete the installation

Choose one of the following installation methods:

Option A: Web-based installation

Open your browser and navigate to http://dxpr-cms.ddev.site or https://dxpr-cms.ddev.site to access the Drupal installation wizard. Complete the installation steps to set up your site.

Option B: Interactive TUI wizard

Run the interactive installer which guides you through each step — recipe selection, site name, API key, languages, and admin credentials:

ddev exec bin/dxpr-install

Option C: Non-interactive CLI installation

For automated or scripted installations:

ddev exec bin/dxpr-install \
  --api-key='YOUR_DXPR_API_KEY' \
  --all-recipes \
  --site-name='My Site' \
  --admin-pass='admin' \
  --no-interaction

With specific recipes and languages:

ddev exec bin/dxpr-install \
  --api-key='YOUR_DXPR_API_KEY' \
  --recipes="News,Events,Multilingual" \
  --languages="nl,de,fr" \
  --site-name='My Site' \
  --no-interaction

Replace YOUR_DXPR_API_KEY with your actual DXPR API key from app.dxpr.com/getting-started. Run bin/dxpr-install --help for all available options.

Option D: Advanced — raw drush site-install

For direct control over the installation process using drush form key parameters:

ddev drush site-install dxpr_cms_installer \
  "installer_recipes_form.add_ons=Case Studies|Events|Forms|Google Analytics|News|SEO Tools|Multilingual" \
  site_name='My Site' \
  dxpr_cms_installer_keys.dxpr_key='YOUR_DXPR_API_KEY' -y

Available recipes: Case Studies, Events, Forms, Google Analytics, News, SEO Tools, Multilingual. Use * for all recipes.

Step 7: Install optional recipes after installation

If you want to add recipes later, install them manually:

ddev drush recipe ../recipes/dxpr_cms_case_study
ddev drush recipe ../recipes/dxpr_cms_events
ddev drush recipe ../recipes/dxpr_cms_forms
ddev drush recipe ../recipes/dxpr_cms_news
ddev drush recipe ../recipes/dxpr_cms_multilingual
ddev drush recipe ../recipes/dxpr_cms_google_analytics
ddev drush recipe ../recipes/dxpr_cms_seo_tools

Complete Module Reference

DXPR CMS includes 88 carefully selected Drupal modules organized by functionality to provide comprehensive capabilities out of the box:

AI Modules

  • ai - Core AI framework providing infrastructure for AI integrations including content generation and analysis
  • ai_agents - AI agents framework enabling autonomous AI assistants for content creation and management tasks
  • ai_checklist - Interactive AI-powered checklists for guiding content creation and ensuring quality standards
  • ai_content_strategy - AI-powered content strategy tools for planning, optimizing and analyzing content effectiveness and engagement
  • ai_social_posts - AI-powered social media post generation for content promotion
  • ai_social_posts_linkedin - LinkedIn-specific AI social post generation capabilities with specialized formatting and engagement optimization (submodule of ai_social_posts)
  • ai_social_posts_linkedin_article - Generate LinkedIn article posts using AI for long-form professional content (submodule of ai_social_posts)
  • ai_sorting - AI-powered content sorting and prioritization based on relevance and engagement potential
  • ai_image_alt_text - Automatically generates accessible alt text for images using AI image recognition and analysis
  • ai_provider_dxpr - DXPR AI provider integration offering free access to multiple AI models including OpenAI, Claude, Gemini, and others through DXPR's unified API
  • analyze_ai_brand_voice - AI-powered brand voice analysis ensuring content consistency with organizational tone and messaging guidelines
  • analyze_ai_content_marketing_audit - AI-powered content marketing audit analyzing effectiveness, engagement potential, and optimization opportunities
  • analyze_ai_content_security_audit - AI-powered security audit scanning content for potential security vulnerabilities and compliance issues
  • analyze_ai_sentiments - Sentiments analysis using AI to evaluate emotional tone and reader perception of content
  • ckeditor_ai_agent - AI assistant integrated into CKEditor for real-time writing suggestions and content improvements
  • rl - Reinforcement Learning module providing machine learning capabilities for content optimization
