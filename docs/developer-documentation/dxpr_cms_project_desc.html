Getting Started with DXPR CMS

Follow these steps to install DXPR CMS:

Step 1: Get a free DXPR API key

Create a free account and get your API key at dxpr.com/user/free-registration. This unlocks DXPR Builder page building and AI features.

Step 2: Install DDEV

Install DDEV if you haven't already.

Step 3: Clone the repository

git clone https://github.com/dxpr/dxpr_cms.git

Step 4: Navigate to the project directory

cd dxpr_cms

Step 5: Start the DDEV environment

ddev start

Step 6: Complete the installation

Choose one of the following installation methods:

Option A: Web-based installation

After the environment starts, follow the link provided in the terminal to access the Drupal installation wizard. Complete the installation steps to set up your site.

Option B: Command-line installation with DXPR API key

For automated installation with your DXPR Builder API key:

ddev drush site-install dxpr_cms_installer dxpr_cms_installer_api_keys_configuration.json_web_token='YOUR_DXPR_API_KEY' -y

Replace YOUR_DXPR_API_KEY with your actual DXPR Builder product key from app.dxpr.com/getting-started.

Step 7: Install optional recipes

During the web-based installation, you can select additional recipes (Case Studies, Events, Forms, Analytics, News, SEO Tools) to customize your site.

If you used command-line installation or want to add recipes later, install them manually:

ddev drush recipe ../recipes/dxpr_cms_case_study
ddev drush recipe ../recipes/dxpr_cms_events  
ddev drush recipe ../recipes/dxpr_cms_forms
ddev drush recipe ../recipes/dxpr_cms_news
ddev drush recipe ../recipes/dxpr_cms_google_analytics
ddev drush recipe ../recipes/dxpr_cms_seo_tools
