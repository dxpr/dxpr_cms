# List of modules used in DXPR CMS

DXPR CMS comes pre-configured with a comprehensive collection of Drupal modules to provide a complete content management and website building experience. Here are the key modules included:

## AI & Content Generation

- **[AI (Artificial Intelligence)](https://www.drupal.org/project/ai)** - Core AI framework with support for 400+ AI models
- **[AI Agents](https://www.drupal.org/project/ai_agents)** - Advanced AI agent orchestration system
- **[AI Provider DXPR](https://www.drupal.org/project/ai_provider_dxpr)** - DXPR's AI provider with extended content capabilities
- **[CKEditor AI Agent](https://www.drupal.org/project/ckeditor_ai_agent)** - AI-powered content creation in CKEditor with slash commands
- **[AI Image Alt Text](https://www.drupal.org/project/ai_image_alt_text)** - Automatic AI-generated alt text for images
- **[AI Social Posts](https://www.drupal.org/project/ai_social_posts)** - AI-powered social media content generation
- **[AI Content Strategy](https://www.drupal.org/project/ai_content_strategy)** - AI-driven content planning and strategy
- **[AI Checklist](https://www.drupal.org/project/ai_checklist)** - AI-powered content quality checklists
- **[AI Sorting](https://www.drupal.org/project/ai_sorting)** - Intelligent content sorting with AI
- **[AI TMGMT](https://www.drupal.org/project/ai_tmgmt)** - AI-powered translation management

## Page Building & Design

- **[DXPR Builder](https://www.drupal.org/project/dxpr_builder)** - Visual drag-and-drop page builder
- **[DXPR Theme Helper](https://www.drupal.org/project/dxpr_theme_helper)** - Enhanced theming capabilities
- **[DXPR CMS Layouts](https://www.drupal.org/project/dxpr_cms_layouts)** - Pre-built layout templates
- **[Field Group](https://www.drupal.org/project/field_group)** - Organize form fields into groups
- **[Block Classes](https://www.drupal.org/project/block_classes)** - Add custom CSS classes to blocks

## Content Management & Editing

- **[Add Content by Bundle](https://www.drupal.org/project/add_content_by_bundle)** - Streamlined content creation
- **[Autosave Form](https://www.drupal.org/project/autosave_form)** - Automatic form saving
- **[Default Content](https://www.drupal.org/project/default_content)** - Demo content and examples
- **[Diff](https://www.drupal.org/project/diff)** - Content revision comparison
- **[ACE Editor](https://www.drupal.org/project/ace_editor)** - Advanced code editor interface

## SEO & Marketing

- **[SEO Checklist](https://www.drupal.org/project/seo_checklist)** - SEO optimization checklist
- **[Google Tag](https://www.drupal.org/project/google_tag)** - Google Analytics and Tag Manager integration
- **[HrefLang](https://www.drupal.org/project/hreflang)** - Multilingual SEO support
- **[Easy Breadcrumb](https://www.drupal.org/project/easy_breadcrumb)** - Enhanced breadcrumb navigation

## User Experience & Interface

- **[Admin Toolbar](https://www.drupal.org/project/admin_toolbar)** - Enhanced administrative toolbar
- **[Gin Toolbar](https://www.drupal.org/project/gin_toolbar)** - Modern admin toolbar styling
- **[Gin LB](https://www.drupal.org/project/gin_lb)** - Layout Builder integration for Gin theme
- **[Better Exposed Filters](https://www.drupal.org/project/better_exposed_filters)** - Improved view filters
- **[Dashboard](https://www.drupal.org/project/dashboard)** - Administrative dashboard

## Media & Files

- **[Crop](https://www.drupal.org/project/crop)** - Image cropping functionality
- **[Focal Point](https://www.drupal.org/project/focal_point)** - Responsive image focal points

## Forms & Security

- **[Captcha](https://www.drupal.org/project/captcha)** - Spam protection for forms
- **[Friendly Captcha](https://www.drupal.org/project/friendlycaptcha)** - Privacy-friendly captcha alternative
- **[Honeypot](https://www.drupal.org/project/honeypot)** - Invisible spam protection
- **[Contact Block](https://www.drupal.org/project/contact_block)** - Contact forms in blocks

## Location & Mapping

- **[Address](https://www.drupal.org/project/address)** - Address field management
- **[Geocoder](https://www.drupal.org/project/geocoder)** - Geocoding services integration
- **[Geofield](https://www.drupal.org/project/geofield)** - Geographic data storage

## Content Analysis & Quality

- **[Analyze](https://www.drupal.org/project/analyze)** - Content analysis framework
- **[Analyze AI Brand Voice](https://www.drupal.org/project/analyze_ai_brand_voice)** - AI-powered brand voice analysis
- **[Analyze AI Content Marketing Audit](https://www.drupal.org/project/analyze_ai_content_marketing_audit)** - Content marketing evaluation
- **[Analyze AI Content Security Audit](https://www.drupal.org/project/analyze_ai_content_security_audit)** - Security-focused content analysis
- **[Analyze AI Sentiments](https://www.drupal.org/project/analyze_ai_sentiments)** - Sentiment analysis for content

## Workflow & Automation

- **[ECA (Event-Condition-Action)](https://www.drupal.org/project/eca)** - No-code workflow automation
- **[BPMN.io](https://www.drupal.org/project/bpmn_io)** - Business process modeling
- **[Scheduler Content Moderation Integration](https://www.drupal.org/project/scheduler_content_moderation_integration)** - Schedule content state changes

## Development & Tools

- **[CTools](https://www.drupal.org/project/ctools)** - Developer tools and APIs
- **[Automatic Updates](https://www.drupal.org/project/automatic_updates)** - Automated security updates
- **[Project Browser](https://www.drupal.org/project/project_browser)** - In-admin module browser

## Additional Functionality

- **[Token](https://www.drupal.org/project/token)** - Dynamic text replacement
- **[Views Bootstrap](https://www.drupal.org/project/views_bootstrap)** - Bootstrap styling for views
- **[Smart Trim](https://www.drupal.org/project/smart_trim)** - Intelligent text trimming
- **[Max Length](https://www.drupal.org/project/maxlength)** - Character limit indicators
- **[Date Augmenter](https://www.drupal.org/project/date_augmenter)** - Enhanced date functionality
- **[Add to Cal Augment](https://www.drupal.org/project/addtocal_augment)** - Calendar integration
- **[Checklistapi](https://www.drupal.org/project/checklistapi)** - Checklist framework
- **[Markdownify](https://www.drupal.org/project/markdownify)** - Markdown support
- **[Statistics](https://www.drupal.org/project/statistics)** - Content statistics tracking
